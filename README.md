# Web Programming — Laboratory 1

Навчальний PHP-проєкт для вивчення Git, GitHub та безперервної інтеграції.

## Мета

Налаштувати командну роботу через Pull Requests, перевірку стилю коду Laravel Pint і модульні тести PHPUnit у GitHub Actions.

## Запланований функціонал

- Додавання та віднімання чисел у сервісі Calculator.
- Автоматична перевірка форматування та модульних тестів.
- Захист гілки main та використання GitHub Secrets.
- Планування задач через Issues і Kanban-дошку GitHub Projects.
